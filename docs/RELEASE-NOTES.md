# DocuFlow Desktop 1.0.0 – projektcsomag

## Tartalom
- Electron desktop alkalmazás
- Helyi SQLite-adatbázis és CRUD funkciók
- PDF export
- Ügyfél-, dokumentum- és sablonkezelés
- Windows/macOS/Linux electron-builder célkonfiguráció
- Magyar dokumentáció

## Ismert hiányosságok
- A sablonok még nem kapcsolódnak automatikusan a dokumentumkészítőhöz.
- A sablonok nem töltődnek be automatikusan a dokumentumszerkesztőbe.
- A PDF Unicode betűkészletet igényel; a DejaVu Sans fontot az assets mappában kell elhelyezni.
- A platformonkénti telepítők ebben a csomagban nincsenek előre lefordítva.
- Függőségtelepítés és célplatformos QA szükséges.

Ez fejlesztési alap és első funkcionális desktop prototípus, nem tanúsított számlázóprogram.
